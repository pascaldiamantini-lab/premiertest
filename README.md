# Horizon

Application web en français pour suivre ses objectifs à court, moyen et long terme, adaptée aux téléphones.

## Développement

Avec Node.js installé, exécuter `npm start`. Le port par défaut est 3000. Vérifier la syntaxe avec `npm run check`. Aucune dépendance à installer.

## Publication sur GitHub Pages

Dans le dépôt GitHub, ouvrir **Settings → Pages**. Dans **Build and deployment**, choisir **Deploy from a branch**, puis la branche **main**, le dossier **/ (root)** et enregistrer.

L’adresse attendue après publication est https://pascaldiamantini-lab.github.io/premiertest/ .

Les objectifs sont enregistrés dans le navigateur de chaque appareil, sans synchronisation. Utiliser le bouton d’export pour les sauvegarder. Les premiers objectifs affichés sont des exemples modifiables.
